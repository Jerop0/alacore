## Implementation notes

- Use the light horizontal logo on the dark header and footer.
- Use the dark horizontal logo on white documents and pages.
- Use the mark for favicon, social avatar, and compact mobile positions.
- The mark is two independent A forms: a taller A on the left and a smaller A on the right. Never connect them into an M.
- Keep the Core circle between the two A forms and preserve the clear gap before the right A.
- Treat blue as an accent, not a page background color.
- Use the website concept as layout guidance; use the SVG and CSS files as implementation assets.
